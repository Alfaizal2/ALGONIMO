4.1 Arithmetic Operators in C

Arithmetic operators in C are used to perform mathematical operations such as addition, subtraction, multiplication, division, and modulus. These operators work on numeric data types (like int and float) and are used in almost every C program.

  • Perform basic mathematical calculations
  • Used with integers and floating-point numbers
  • Follow operator precedence (BODMAS-like rules)
  • Commonly used inside expressions and formulas

Overview of Arithmetic Operators

Operator Symbol Description Example Output
Addition + Adds two values 5 + 3 8
Subtraction - Subtracts second from first 10 - 4 6
Multiplication * Multiplies two numbers 6 * 3 18
Division / Divides first by second 9 / 2 4 (int), 4.5 (float)
Modulus % Returns remainder 10 % 3 1

1. Addition (+)

Adds two numbers and returns their sum.

#include <stdio.h>

int main() {
    int a = 5, b = 3;
    int result = a + b;
    printf("Sum = %d", result);
    return 0;
}
Output: Sum = 8

2. Subtraction (-)

Subtracts the second number from the first.

#include <stdio.h>

int main() {
    int x = 10, y = 4;
    printf("Difference = %d", x - y);
    return 0;
}
Output: Difference = 6

3. Multiplication (*)

Multiplies two values.

#include <stdio.h>

int main() {
    int a = 6, b = 3;
    printf("Product = %d", a * b);
    return 0;
}
Output: Product = 18

4. Division (/)

Performs division. Important: dividing two integers results in integer division. 

#include <stdio.h>

int main() {
    int a = 9, b = 2;
    printf("Quotient = %d", a / b);
    return 0;
}
Output: Quotient = 4

Floating division example:

printf("%f", 9.0 / 2);  // 4.500000

5. Modulus (%)

Returns the remainder of a division.

#include <stdio.h>

int main() {
    int a = 10, b = 3;
    printf("Remainder = %d", a % b);
    return 0;
}
Output: Remainder = 1
