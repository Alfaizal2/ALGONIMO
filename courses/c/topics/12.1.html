12.1 Command Line Arguments

Introduction

Command-line arguments allow users to pass values to a C program during execution. This makes programs flexible by avoiding hard-coded inputs or repeated use of scanf().

Syntax

The main() function receives arguments in this form:

int main(int argc, char *argv[])
  • argc → Argument Count (number of arguments)
  • argv[] → Argument Vector (array of strings)

Note: argv[0] always contains the program name.

Example: Print All Arguments

#include <stdio.h>

int main(int argc, char *argv[]) {
    printf("Total arguments: %d\n", argc);

    for (int i = 0; i < argc; i++) {
        printf("Argument %d: %s\n", i, argv[i]);
    }

    return 0;
}

Run as: ./program Hello World

Output:
Total arguments: 3
Argument 0: ./program
Argument 1: Hello
Argument 2: World

Common Use Cases

  • Passing a filename to open
  • Providing flags (e.g., -n, -v)
  • Sending multiple inputs without using scanf()
  • Automating tasks through scripts
