3.6 Escape Sequences in C

What Are Escape Sequences?

Escape sequences are special character combinations used in C programming to represent actions or characters that can’t be typed directly, such as a new line, tab, or printing quotes inside a string. They always begin with a backslash ( \ ).

  • Used for formatting text output
  • Represent invisible control characters
  • Allow printing quotes and slashes
  • Used inside printf() and strings

Common Escape Sequences

Escape Sequence Description Example Output
\n New Line Hello
World
\t Tab Space Hello World
\\ Backslash \
\' Single Quote '
\" Double Quote "
\r Carriage Return (Cursor moves to line start)
\b Backspace (Removes previous character)

Example Program

#include <stdio.h>

int main() {
    printf("Hello\\nWorld:\\n");
    printf("Line1\\tTabbed\\n");
    printf("Printing quotes: \\\"Hello\\\"\\n");
    printf("Backslash: \\\\");
    return 0;
}
