2.4 Structure of a C Program

Overview

Every C program follows a specific structure. Understanding this layout helps you write clean, readable, and error-free programs. All C programs share the same foundational building blocks.

Basic Structure of a C Program

#include <stdio.h>               // Header File

int main()                     // Main Function
{                

printf("Hello, World!\n");  // Your logic goes here

return 0;                 // Return statement
}

This is the simplest and most common structure you'll see in C programs.

Parts of a C Program Explained

  • 1. Header Files
    Lines starting with #include bring external libraries into your program.
    Example: #include <stdio.h> allows you to use printf().
  • 2. main() Function
    Execution of every C program begins in the main() function.
  • 3. Body / Statements
    All code inside { } is executed line by line. Example: printf("Hello");
  • 4. Return Statement
    return 0; tells the operating system that the program ended correctly.

Important Notes

  • C is case-sensitive (e.g., Main ≠ main).
  • Every statement must end with a semicolon ;.
  • Curly braces { } define program blocks.
  • Comments help explain your code and are ignored by the compiler.
