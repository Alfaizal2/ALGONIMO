3.1 Keywords & Identifiers

Explanation

In C programming, keywords are reserved words with special meaning defined by the language. You cannot use them as variable names or identifiers.

Identifiers are the names used for variables, functions, arrays, etc. They are created by the programmer and must follow certain naming rules.

Keywords

C has 32 standard keywords. Some of the most common include:

  • int, float, char – used for declaring data types
  • if, else, switch – used for decision making
  • while, for, do – used for loops
  • return, break, continue

Rules for Identifiers

  • Must begin with a letter (A-Z, a-z) or underscore (_)
  • Cannot begin with a digit
  • Can contain letters, digits, and underscores
  • Cannot be a keyword
  • Are case-sensitive (e.g., Value vs value)

Sample Code

#include <stdio.h>

int main() {
    int age = 20;   // 'age' is an identifier
    printf("Age: %d", age);

    return 0;
}
