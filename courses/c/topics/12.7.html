12.7 const and volatile in C

Understanding const

The const keyword is used to declare variables whose values cannot be modified after initialization. It protects data from accidental changes. 

const int age = 30;
age = 40;   // ❌ Error: cannot modify a const variable

Using const makes code safer and more readable.

Understanding volatile

volatile tells the compiler:

✅ The value of this variable may change unexpectedly.
✅ Do NOT optimize it.

It is used when variables can change due to:

  • Hardware interrupts
  • Multithreading
  • External devices
  • Memory-mapped registers
volatile int flag;

while (flag == 0) {
    // system waits until hardware updates the flag
}

Why Use volatile?

  • Prevents compiler from skipping variable checks
  • Ensures every read/write accesses real memory
  • Essential in embedded software
  • Prevents incorrect optimizations

Using const with Pointers

const int *p;      
// value cannot change, pointer can change

int *const p2 = &x;  
// pointer fixed, value can change

const int *const p3 = &x; 
// both value and pointer are constant

Understanding pointer–const combinations is crucial for APIs and library design.

Summary

  • const → variable value cannot be changed
  • volatile → value may change anytime externally
  • Together, they form: 
    const volatile int sensorValue;
    Useful for hardware inputs.
