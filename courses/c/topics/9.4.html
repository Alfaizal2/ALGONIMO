9.4 Nested Structures

What are Nested Structures?

A nested structure is a structure placed inside another structure. This helps organize complex data such as:

  • Students with Date of Birth
  • Employees with Address
  • Orders with Product details

Nested structures allow hierarchical grouping of relevant data.

Syntax

struct Inner {
    data_type member1;
    ...
};

struct Outer {
    struct Inner innerMember;   // Nested structure
    data_type otherMember;
};
