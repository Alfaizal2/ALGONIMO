10.4 Modes of File Opening

Explanation

When opening a file using fopen(), you must specify a file mode. This tells the compiler how you want to access the file: read, write, modify, or append.

File Modes in C

Mode Description
"r" Open for reading. File must already exist.
"w" Open for writing. Creates a new file or overwrites an existing one.
"a" Open for appending. Creates file if missing.
"r+" Open for both reading and writing. File must already exist.
"w+" Read + write. Overwrites existing file or creates a new one.
"a+" Read + append. Creates file if missing.

Example: Using "a" Mode

#include <stdio.h>

int main() {
    FILE *fp = fopen("log.txt", "a");

    if (fp != NULL) {
        fprintf(fp, "New entry logged.\n");
        fclose(fp);
    }
    return 0;
}
Note: Using "a" mode ensures new content is added at the end, without deleting existing data.

Summary

  • Choose the correct fopen() mode based on reading, writing, or appending.
  • Modes with + allow both reading and writing.
  • Warning: "w" and "w+" erase existing file content.
