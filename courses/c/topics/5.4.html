5.4 Nested Loops in C

Introduction

A nested loop is a loop inside another loop. The inner loop executes completely for every iteration of the outer loop. Nested loops are commonly used for:

  • Patterns and matrix operations
  • 2D arrays
  • Working with rows and columns
  • Repeated tasks inside another repeated task

Example: Nested for Loops

#include <stdio.h>

int main() {
    for (int i = 1; i <= 3; i++) {
        for (int j = 1; j <= 2; j++) {
            printf("i = %d, j = %d\n", i, j);
        }
    }
    return 0;
}
Output:
i = 1, j = 1
i = 1, j = 2
i = 2, j = 1
i = 2, j = 2
i = 3, j = 1
i = 3, j = 2

Explanation

  • Outer loop → runs 3 times (i = 1 to 3)
  • Inner loop → runs 2 times for each outer iteration
  • Total iterations = 3 × 2 = 6
  • Inner loop completes every cycle before outer loop moves to the next value

You Can Nest:

  • for inside for
  • while inside for
  • do-while inside while
  • Any combination of loop types
