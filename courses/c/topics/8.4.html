8.4 Pointers with Functions

Why Use Pointers with Functions?

In C, function arguments are always passed by value. But sometimes we need a function to modify the original variables passed to it.

Using pointers lets us achieve call by reference behavior, meaning the function can directly access and update the original variables.

Example: Swapping Two Numbers

#include <stdio.h>

void swap(int *x, int *y) {
    int temp = *x;  
    *x = *y;        
    *y = temp;      
}

int main() {
    int a = 5, b = 10;

    printf("Before Swap: a = %d, b = %d\n", a, b);
    swap(&a, &b);  
    printf("After Swap: a = %d, b = %d\n", a, b);

    return 0;
}
Output:
Before Swap: a = 5, b = 10
After Swap: a = 10, b = 5

How It Works

  • swap(&a, &b) passes addresses of variables
  • *x and *y access the actual values stored at those addresses
  • Changes inside swap() update a and b directly

Summary Table

Concept Description
*ptr Accesses the value stored at a memory address
&var Gets the address of a variable
Call by Reference Allows modifying original variables inside a function
