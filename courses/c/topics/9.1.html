9.1 Defining Structures

What is a Structure?

A structure in C is a user-defined data type that groups variables of different data types under a single name. It is commonly used to represent real-world entities like:

  • Student (ID, name, marks)
  • Employee (ID, salary, department)
  • Product (price, code, quantity)

Structure Syntax

struct StructureName {
    data_type member1;
    data_type member2;
    ...
};

Declaring variables:

struct StructureName var1, var2;
