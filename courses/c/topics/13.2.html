13.2 Logic-Based Programs

Introduction

Logic-based programs sharpen your problem-solving skills using decisions, loops, and math. Start simple, then optimize your approach.

Popular Logic Programs

  • Check if a number is Armstrong
  • Reverse a number
  • Check if a string is a palindrome
  • Factorial of a number (recursion)
  • Check if a number is a palindrome
  • Find GCD and LCM of two numbers
  • Generate Pascal’s Triangle
  • Count digits, vowels, consonants in a string
  • Sort an array (Bubble Sort)

Quick Cheat-Sheet

Problem Core Idea
Palindrome (number/string) Reverse and compare with original
Armstrong number Sum of each digit power(len) equals number
Factorial n! = n × (n−1)! with base case 0!/1! = 1
GCD / LCM Euclid’s algorithm; LCM = (a×b)/GCD
Bubble Sort Swap adjacent if out of order; repeat passes

Example 1: Palindrome Number

#include <stdio.h>

int main() {
    int num, rev = 0, rem, original;
    printf("Enter a number: ");
    if (scanf("%d", &num) != 1) return 0;
    original = num;

    while (num != 0) {
        rem = num % 10;
        rev = rev * 10 + rem;
        num /= 10;
    }

    if (original == rev)
        printf("Palindrome!\n");
    else
        printf("Not a palindrome.\n");

    return 0;
}

Example 2: Armstrong Number

#include <stdio.h>
#include <math.h>

int main() {
    int n, temp, digits = 0;
    long long sum = 0;
    printf("Enter a number: ");
    if (scanf("%d", &n) != 1) return 0;

    temp = n;
    while (temp != 0) { digits++; temp /= 10; }
    temp = n;

    while (temp != 0) {
        int d = temp % 10;
        sum += (long long)pow(d, digits);
        temp /= 10;
    }

    if (sum == n) printf("Armstrong number\n");
    else          printf("Not an Armstrong number\n");
    return 0;
}
