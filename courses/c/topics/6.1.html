6.1 Function Declaration and Definition

Introduction

Functions in C allow you to break a program into smaller, reusable components. They improve:

  • Modularity
  • Readability
  • Maintainability
  • Reusability

Syntax

// Function declaration (prototype)
return_type function_name(parameter_list);

// Function definition
return_type function_name(parameter_list) {
    // function body
}

Example Program

#include <stdio.h>

// Function declaration
void greet();

int main() {
    greet();   // function call
    return 0;
}

// Function definition
void greet() {
    printf("Welcome to Algonimo!\n");
}

Output

Welcome to Algonimo!

Explanation

  • Function declaration: Tells the compiler about the function.
  • Function call: Executes the function inside main().
  • Function definition: Contains actual statements to run.
  • Functions reduce code duplication and make programs well-structured.

Why Use Functions?

Feature Description
Reusability Write once and use many times.
Modularity Break a big program into smaller modules.
Debugging Easier to test and find errors.
Readability Makes code clean and easy to understand.
