2.3 Compiling and Running C Code

Introduction

Once you write a C program, the next step is to compile it. The compiler checks your code for errors and converts it into machine-readable form. After successful compilation, you can run the program and see the output.

Here’s a simple and clear guide to compiling and running C programs using the GCC compiler.

Steps to Compile and Run a C Program

  • Save your file with a .c extension (for example: hello.c).
  • Open a terminal, command prompt, or VS Code terminal.
  • Compile the program using GCC: 
    gcc hello.c -o hello
  • If there are no errors, run the program: 
    ./hello

Example Terminal Output

This is how it looks when you compile and run hello.c:

$ gcc hello.c -o hello
$ ./hello
Hello, World!

Your program output appears on the next line — in this case, the classic “Hello, World!”.

If You Get Errors

Check the following common issues:

  • Did you type the code exactly as shown?
  • Did you save the file with a .c extension?
  • Is your GCC compiler installed correctly?
  • Are you running the command from the correct folder?

Compilers provide error messages — read them carefully as they usually point to the line causing the issue.
