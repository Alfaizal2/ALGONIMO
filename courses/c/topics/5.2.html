5.2 switch Statement in C

Introduction

The switch statement is used when you need to choose one option out of many based on the value of a variable or expression. It is a cleaner alternative to multiple else-if conditions.

Syntax

switch (expression) {
    case value1:
        // code block
        break;

    case value2:
        // code block
        break;

    ...

    default:
        // default block
}

Explanation

  • expression is evaluated once.
  • The result is compared with each case value.
  • When a match is found, that code block executes.
  • break prevents fall-through to the next case.
  • default runs when no case matches (optional).

Example

#include <stdio.h>

int main() {
    int day = 3;

    switch(day) {
        case 1:
            printf("Monday\n");
            break;

        case 2:
            printf("Tuesday\n");
            break;

        case 3:
            printf("Wednesday\n");
            break;

        case 4:
            printf("Thursday\n");
            break;

        case 5:
            printf("Friday\n");
            break;

        default:
            printf("Weekend\n");
    }

    return 0;
}
Wednesday

Output Explanation

The value of day is 3. It matches case 3, so the program prints:
"Wednesday"
