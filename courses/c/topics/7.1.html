7.1 1D and 2D Arrays in C

What Are Arrays?

An array in C is a collection of elements of the same data type stored in contiguous memory locations.

✅ 1D Array: Stores data in a single list (linear structure). ✅ 2D Array: Stores data in rows and columns (matrix structure).

Syntax

// 1D Array
datatype array_name[size];

// 2D Array
datatype array_name[rows][columns];

Example: 1D Array

#include <stdio.h>

int main() {
    int numbers[5] = {10, 20, 30, 40, 50};

    for (int i = 0; i < 5; i++) {
        printf("%d ", numbers[i]);
    }

    return 0;
}

Output

10 20 30 40 50

Example: 2D Array

#include <stdio.h>

int main() {
    int matrix[2][3] = {
        {1, 2, 3},
        {4, 5, 6}
    };

    for (int i = 0; i < 2; i++) {
        for (int j = 0; j < 3; j++) {
            printf("%d ", matrix[i][j]);
        }
        printf("\n");
    }

    return 0;
}

Output

1 2 3
4 5 6

How It Works?

  • 1D Array: Access elements using array[i].
  • 2D Array: Use nested loops to access rows and columns using array[i][j].
  • The 2D array is essentially an array of 1D arrays.

Summary Table

Type Structure Access Method
1D Array Linear array[i]
2D Array Matrix/Table array[i][j]
