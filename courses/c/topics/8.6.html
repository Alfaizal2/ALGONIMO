8.6 Pointers and Strings

Understanding Pointers and Strings

In C, strings are stored as character arrays terminated by a null character '\0'. Pointers allow efficient string traversal, modification, and function argument handling.

  • Strings = Array of characters
  • Pointers can traverse characters one by one
  • Useful for dynamic string operations

How It Works

  • str holds the address of the first character
  • *str gives the current character
  • str++ moves the pointer to the next character in memory
