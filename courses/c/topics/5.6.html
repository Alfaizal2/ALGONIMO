5.6 Flowcharts for Decision Making

Introduction

Flowcharts are visual diagrams used to represent decision-making processes in programming. They are especially useful for understanding:

  • if statements
  • if-else conditions
  • switch decision structures

Flowcharts help visualize complicated logic before writing actual C code.

Basic Flowchart Symbols

Symbol Meaning
🔷 Diamond Decision (yes/no)
⬛ Rectangle Process / Operation
🟦 Parallelogram Input / Output
⏹ Oval Start / End

Example 1: if-else Flowchart

#include <stdio.h>

int main() {
    int age;
    printf("Enter age: ");
    scanf("%d", &age);

    if(age >= 18)
        printf("You are eligible to vote.\n");
    else
        printf("You are not eligible.\n");

    return 0;
}
Sample Output:
Enter age: 20
You are eligible to vote.

Example 2: switch Flowchart

#include <stdio.h>

int main() {
    int day = 2;

    switch(day) {
        case 1: printf("Monday\n"); break;
        case 2: printf("Tuesday\n"); break;
        default: printf("Invalid\n");
    }

    return 0;
}
Output:
Tuesday

Explanation: The flowchart shows how switch selects one branch based on a matched case.

Why Use Flowcharts?

  • Helps visualize logic before coding
  • Makes complex decisions easier to understand
  • Useful for debugging & teaching beginners
  • Helps plan programs in a structured way
