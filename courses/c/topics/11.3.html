11.3 Memory Leaks & Management

Introduction

When using dynamic memory, managing allocated memory properly is very important. Forgetting to release memory results in a memory leak — unused memory that stays allocated and reduces system performance.

What is a Memory Leak?

A memory leak happens when a program allocates memory but never frees it using free(). Over time, this can slow down or even crash systems. 

// Memory leak example
int *ptr = malloc(100 * sizeof(int));
// Forgot: free(ptr);  → Memory leak!

Preventing Memory Leaks

  • Always pair malloc(), calloc(), realloc() with free().
  • Set pointers to NULL after freeing.
  • Use tools like Valgrind (Linux) to detect leaks.
  • Keep track of memory allocations in large programs.

Example: Safe Memory Management

#include <stdio.h>
#include <stdlib.h>

int main() {
    int *data = malloc(5 * sizeof(int));

    if (data == NULL) {
        printf("Memory allocation failed!\n");
        return 1;
    }

    for (int i = 0; i < 5; i++)
        data[i] = i * 2;

    for (int i = 0; i < 5; i++)
        printf("%d ", data[i]);

    free(data);     // Release memory
    data = NULL;    // Avoid dangling pointer

    return 0;
}
