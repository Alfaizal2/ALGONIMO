4.4 Assignment & Compound Assignment Operators in C

Assignment operators allow you to store values inside variables. The basic operator is =, but C also provides compound assignment operators that make your code cleaner and faster.

  • Used to update variable values efficiently
  • Shorter alternative to writing full arithmetic expressions
  • Commonly used in loops, counters, and calculations

Assignment Operators Overview

Operator Description Example Equivalent To
= Assigns value x = 10 x = 10
+= Add and assign x += 5 x = x + 5
-= Subtract and assign x -= 3 x = x - 3
*= Multiply and assign x *= 2 x = x * 2
/= Divide and assign x /= 4 x = x / 4
%= Modulus and assign x %= 3 x = x % 3

Example: Using Compound Assignment

#include <stdio.h>

int main() {
    int x = 10;

    x += 5;   // x = x + 5   → x = 15
    x *= 2;   // x = x * 2   → x = 30
    x -= 4;   // x = x - 4   → x = 26

    printf("Final result: %d", x);
    return 0;
}
Output: Final result: 26

Explanation:

  • x starts at 10
  • x += 5 → 15
  • x *= 2 → 30
  • x -= 4 → 26

Real-Life Usage Example

#include <stdio.h>

int main() {
    int score = 50;

    score += 10;   // bonus points
    score -= 5;    // penalty
    score *= 2;    // double points event

    printf("Final Score: %d", score);
    return 0;
}
Output: Final Score: 110
