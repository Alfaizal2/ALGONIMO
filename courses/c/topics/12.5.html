12.5 Enum & Typedef

What is an Enum?

An enum (enumeration) is a user-defined type that assigns names to integer constants. It increases readability and avoids using magic numbers in code. 

enum Days { SUN, MON, TUE, WED, THU, FRI, SAT };

By default: SUN = 0, MON = 1, TUE = 2, etc.

Using Enum in a Program

#include <stdio.h>

enum Days { SUN, MON, TUE, WED, THU, FRI, SAT };

int main() {
    enum Days today = WED;

    if (today == WED) {
        printf("It's Wednesday!\\n");
    }

    return 0;
}
Output:
It's Wednesday!

What is Typedef?

typedef gives a new alias name to an existing type. It simplifies complex type declarations and increases readability. 

typedef unsigned int uint;

Now uint can be used in place of unsigned int.

Using Typedef in a Program

#include <stdio.h>

typedef unsigned int uint;

int main() {
    uint age = 25;
    printf("Age: %u\\n", age);

    return 0;
}
Output:
Age: 25
