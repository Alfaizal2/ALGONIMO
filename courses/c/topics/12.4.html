12.4 Macros & Preprocessor Directives

What are Preprocessor Directives?

Preprocessor directives are commands that run before compilation. They start with # and control compilation, file inclusion, debugging, and macro creation.

Common Preprocessor Directives

Directive Description
#include Includes header files
#define Creates macros / constants
#undef Removes a macro definition
#ifdef / #ifndef Conditional compilation blocks

Defining Macros

#define PI 3.14
#define SQUARE(x) ((x) * (x))

Macros are replaced by their value before compilation. Function-like macros can take parameters.

Example: Using Macros

#include <stdio.h>

#define PI 3.14
#define AREA(r) (PI * (r) * (r))

int main() {
    float radius = 5;
    printf("Area = %.2f\n", AREA(radius));
    return 0;
}
Output:
Area = 78.50

Conditional Compilation

#define DEBUG

#ifdef DEBUG
  printf("Debug mode is ON\n");
#endif

Code inside #ifdef runs only if the macro is defined.
