4.2 Relational Operators in C

Relational operators in C are used to compare two values or expressions. They return:

  • 1 → If the condition is true
  • 0 → If the condition is false
  • Commonly used in decision-making (if/else) and loops
  • Work with both integers and floating-point values

Overview of Relational Operators

Operator Symbol Description Example Output
Equal to == Checks if values are equal 5 == 5 1
Not equal to != Checks if values differ 5 != 3 1
Greater than > Left > Right? 6 > 2 1
Less than < Left < Right? 3 < 9 1
Greater or equal >= Left ≥ Right? 7 >= 7 1
Less or equal <= Left ≤ Right? 2 <= 5 1

1. Equal To (==)

#include <stdio.h>

int main() {
    int a = 5, b = 5;
    printf("%d", a == b);
    return 0;
}
Output: 1 (true)

Explanation: Both values are equal, so C returns 1.

2. Not Equal (!=)

#include <stdio.h>

int main() {
    int a = 5, b = 3;
    printf("%d", a != b);
    return 0;
}
Output: 1

Explanation: 5 is not equal to 3 → true.

3. Greater Than (>)

#include <stdio.h>

int main() {
    int a = 10, b = 7;
    printf("%d", a > b);
    return 0;
}
Output: 1

4. Less Than (<)

#include <stdio.h>

int main() {
    int a = 2, b = 8;
    printf("%d", a < b);
    return 0;
}
Output: 1

5. Greater Than or Equal (>=)

#include <stdio.h>

int main() {
    int x = 4, y = 4;
    printf("%d", x >= y);
    return 0;
}
Output: 1

6. Less Than or Equal (<=)

#include <stdio.h>

int main() {
    int x = 3, y = 10;
    printf("%d", x <= y);
    return 0;
}
Output: 1
