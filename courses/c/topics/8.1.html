8.1 Introduction to Pointers

What is a Pointer?

A pointer in C is a variable that stores the memory address of another variable. It is one of the most powerful features in C and is widely used for:

  • Dynamic memory allocation
  • Arrays and strings
  • Functions (pass by reference)
  • Structures

Declaring a Pointer

A pointer is created using the * symbol:

int *ptr;   // pointer to an integer

To assign a memory address, use the & (address-of) operator:

ptr = # // ptr now stores address of num

Example

#include <stdio.h>

int main() {
    int num = 10;
    int *ptr = #

    printf("Value of num = %d\n", num);
    printf("Address of num = %p\n", &num);
    printf("Pointer ptr contains = %p\n", ptr);
    printf("Value at ptr = %d\n", *ptr);

    return 0;
}
Output:
Value of num = 10
Address of num = 0x7ffee5b5d6bc
Pointer ptr contains = 0x7ffee5b5d6bc
Value at ptr = 10

Note: Memory addresses will vary on each run.

Key Pointer Symbols

Symbol Meaning
* Declares a pointer / Dereferences a pointer
& Returns the address of a variable
