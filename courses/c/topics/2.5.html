2.5 main() Function Explained

What is main()?

The main() function is the entry point of every C program. When your program starts, the operating system automatically calls main(). Without main(), your program cannot run.

Standard Syntax

int main() {
    // Code here
    return 0;
}

This is the most common and most recommended version of main().

Explanation of Each Part

  • int – The return type. It tells the OS the program’s result. 0 means success.
  • main – The function name. The compiler looks for main() to begin execution.
  • () – Parentheses for parameters (even if empty).
  • return 0; – Sends a success signal back to the OS.

Common Variants of main()

// 1. With command-line arguments (standard)
int main(int argc, char *argv[]) {
    return 0;
}

// 2. Non-standard version (compiler-specific)
void main() {
    // Avoid using this — not valid in standard C
}
  • int main(int argc, char *argv[]) Used when your program accepts command-line inputs.
  • void main() Not standard — avoid unless using microcontrollers.

Summary

  • Every C program must have exactly one main() function.
  • Execution of the program always begins in main().
  • Always return 0 in standard C programs.
  • Use the command-line version only when needed.
