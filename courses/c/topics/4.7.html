4.7 Ternary Operator in C

Introduction

The ternary operator in C is a compact, shorthand replacement for the if-else statement. It evaluates a condition and returns one of two values depending on whether the condition is true or false. It is the only operator in C that takes three operands, which is why it is called the ternary or conditional operator.

Syntax and Explanation

Operator Syntax Description
?: condition ? expression1 : expression2 Executes expression1 if condition is true; otherwise executes expression2.

Example

#include <stdio.h>

int main() {
    int a = 10, b = 20;
    int max;

    max = (a > b) ? a : b;

    printf("The maximum is: %d", max);

    return 0;
}

Explanation:

  • The condition a > b evaluates to false because 10 is not greater than 20.
  • Therefore, the false expression b is selected.
  • Hence, max becomes 20.
  • The program outputs: The maximum is: 20
