10.2 Reading & Writing Files

Introduction

File handling in C enables reading and writing data to files using functions from <stdio.h>. These functions perform character-level, line-level, or formatted input/output.

  • fprintf() – formatted writing
  • fputs() – write a string
  • fgetc() – read a single character
  • fgets() – read a line of text

Example 1: Writing to a File

#include <stdio.h>

int main() {
    FILE *fp = fopen("sample.txt", "w");

    if (fp == NULL) {
        printf("Unable to open file.\n");
        return 1;
    }

    fprintf(fp, "Welcome to Algonimo!\n");
    fputs("This is C file handling.\n", fp);

    fclose(fp);
    return 0;
}
Output:
Creates sample.txt containing two lines of text.

Example 2: Reading from a File

#include <stdio.h>

int main() {
    char ch;
    FILE *fp = fopen("sample.txt", "r");

    if (fp == NULL) {
        printf("File not found.\n");
        return 1;
    }

    while ((ch = fgetc(fp)) != EOF) {
        putchar(ch);
    }

    fclose(fp);
    return 0;
}
Output:
Prints the content of sample.txt to the screen.

Notes

  • fprintf() behaves like printf() but writes to a file.
  • fgetc() is used for character-by-character reading.
  • fgets() is used for reading strings/lines safely.
  • Always check for NULL after opening a file.
  • Reading stops when EOF (End Of File) is reached.

Summary

  • Use fprintf() or fputs() to write to a file.
  • Use fgetc() or fgets() to read from a file.
  • Always close the file using fclose().
