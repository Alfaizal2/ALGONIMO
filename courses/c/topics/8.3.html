8.3 Pointers with Arrays

Understanding Pointers with Arrays

In C, the name of an array acts like a constant pointer to its first element. This allows pointers to access and manipulate array elements efficiently.

  • arr → points to &arr[0]
  • *(arr + i) → accesses element at index i
  • Pointers make traversal faster and more flexible

Accessing Array Elements Using Pointers

#include <stdio.h>

int main() {
    int arr[] = {10, 20, 30, 40, 50};
    int *ptr = arr;   // same as &arr[0]

    for (int i = 0; i < 5; i++) {
        printf("Element %d = %d\n", i, *(ptr + i));
    }

    return 0;
}
Output:
Element 0 = 10
Element 1 = 20
Element 2 = 30
Element 3 = 40
Element 4 = 50

How It Works

  • ptr stores address of first element
  • ptr + 1 jumps to next integer location
  • *(ptr + i) gives the actual value at that location

Modifying Array Using Pointers

You can update array values directly through pointer arithmetic.

#include <stdio.h>

int main() {
    int arr[] = {1, 2, 3};
    int *ptr = arr;

    *(ptr + 1) = 20;   // modify second element

    for (int i = 0; i < 3; i++) {
        printf("%d ", arr[i]);
    }

    return 0;
}
Output:
1 20 3

Summary Table

Expression Meaning
arr Points to first element
*(arr + i) Gets element at index i
ptr = arr Pointer now points to array
ptr + i Moves pointer to next elements
