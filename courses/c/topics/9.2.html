9.2 Accessing Members

Accessing Structure Members

Once a structure is defined and a variable is created, you can access its members using the dot operator (.). This operator allows you to assign and read values inside a structure variable.

Syntax

struct StructureName var;
var.member1 = value;
var.member2 = value;

The dot operator connects the structure variable with its members.
