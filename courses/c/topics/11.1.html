11.1 malloc() and calloc()

Introduction

In C, malloc() and calloc() are used to allocate memory dynamically at runtime. These functions are declared in <stdlib.h> and return a pointer to the allocated memory block.

malloc()

malloc() allocates one large block of memory. The allocated memory contains garbage values. 

#include <stdlib.h>

int *ptr;
ptr = (int *) malloc(5 * sizeof(int));

Important: Always check if ptr == NULL before using it.

calloc()

calloc() allocates memory in multiple blocks and initializes all bytes to zero. 

#include <stdlib.h>

int *ptr;
ptr = (int *) calloc(5, sizeof(int));

malloc() vs calloc()

Aspect malloc() calloc()
Initialization Garbage values All values set to 0
Syntax malloc(size) calloc(n, size)
Speed Faster Slightly slower (due to initialization)

Example: Using calloc()

#include <stdio.h>
#include <stdlib.h>

int main() {
    int *arr;
    int i;

    arr = (int *) calloc(5, sizeof(int));

    if (arr == NULL) {
        printf("Memory allocation failed!");
        return 1;
    }

    for (i = 0; i < 5; i++) {
        printf("arr[%d] = %d\n", i, arr[i]);
    }

    free(arr);
    return 0;
}
Output:
arr[0] = 0
arr[1] = 0
arr[2] = 0
arr[3] = 0
arr[4] = 0

Summary

  • malloc() allocates raw memory (garbage values).
  • calloc() allocates and initializes memory to zero.
  • Always check for NULL after allocation.
  • Use free() to release allocated memory.
