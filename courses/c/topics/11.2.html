11.2 realloc() and free()

Introduction

After using malloc() or calloc(), you might need to resize or release the allocated memory. For this, C provides:

  • realloc() – Resize allocated memory
  • free() – Release allocated memory

realloc()

realloc() changes the size of an already allocated memory block. It may move the block to a new location. 

#include <stdlib.h>

int *ptr;
ptr = malloc(3 * sizeof(int));
ptr = realloc(ptr, 5 * sizeof(int));

Note: Always check if realloc() returned NULL.

free()

free() releases the memory back to the system. Not freeing memory causes memory leaks. 

#include <stdlib.h>

int *ptr = malloc(10 * sizeof(int));
free(ptr);
ptr = NULL;

Example: realloc() and free()

#include <stdio.h>
#include <stdlib.h>

int main() {
    int *arr;
    int i;

    arr = (int *) malloc(3 * sizeof(int));
    if (arr == NULL) {
        printf("Initial allocation failed!");
        return 1;
    }

    for (i = 0; i < 3; i++)
        arr[i] = i + 1;

    arr = (int *) realloc(arr, 5 * sizeof(int));
    if (arr == NULL) {
        printf("Reallocation failed!");
        return 1;
    }

    for (i = 3; i < 5; i++)
        arr[i] = i + 1;

    for (i = 0; i < 5; i++)
        printf("arr[%d] = %d\n", i, arr[i]);

    free(arr);
    return 0;
}
Output:
arr[0] = 1
arr[1] = 2
arr[2] = 3
arr[3] = 4
arr[4] = 5
