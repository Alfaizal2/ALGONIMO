9.3 Array of Structures

What is an Array of Structures?

An array of structures stores multiple structure variables under one name. It is extremely useful for managing lists such as:

  • Students
  • Employees
  • Products
  • Records of any kind

Each element of the array is a full structure with its own members.

Syntax

struct StructureName {
    data_type member1;
    data_type member2;
    ...
};

struct StructureName arrayName[size];

Quick Summary

Concept Description
struct S arr[n]; Creates an array of n structures
arr[i].member Accesses a member of the i-th structure
strcpy(arr[i].name, "text"); Assigns string to structure member
