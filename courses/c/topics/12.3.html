12.3 Header Files in C

What is a Header File?

A header file in C (with a .h extension) contains:

  • Function declarations
  • Macros
  • Constants
  • Data type definitions

Header files help keep code organized and reusable, especially in large projects.

Common Standard Header Files

Header Purpose
<stdio.h> Input/Output functions
<stdlib.h> Memory allocation, system commands
<string.h> String handling operations
<math.h> Mathematical functions

Creating a Custom Header File

myfunctions.h

// myfunctions.h
void greet();

myfunctions.c

#include <stdio.h>
void greet() {
    printf("Hello from header!\\n");
}

main.c

#include "myfunctions.h"

int main() {
    greet();
    return 0;
}

Include Guards

Include guards prevent the same header file from being included multiple times. 

#ifndef MYFUNCTIONS_H
#define MYFUNCTIONS_H

void greet();

#endif
