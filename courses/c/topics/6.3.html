6.3 Parameters: Call by Value

What is Call by Value?

In C, all function arguments are passed using the Call by Value method. This means a copy of the original variable is passed to the function. Any changes made to the parameter inside the function do not affect the original variable.

Syntax

void functionName(int param) {
    // param is a copy of the original argument
}

Example Program

#include <stdio.h>

void changeValue(int x) {
    x = 100;
    printf("Inside function: x = %d\n", x);
}

int main() {
    int a = 50;
    changeValue(a);      // Passing a COPY of 'a'
    printf("Inside main: a = %d\n", a);
    return 0;
}

Output

Inside function: x = 100
Inside main: a = 50

Output Explanation

The value of x changed to 100 inside the function, but the original variable a in main() remained 50. This confirms that C passes only a copy of the variable.
