4.8 Precedence and Associativity in C

Introduction

In C programming, when an expression contains multiple operators, the compiler must decide which operator to evaluate first. This is controlled by:

  • Operator Precedence – Determines priority between operators.
  • Associativity – Determines whether evaluation happens left-to-right or right-to-left when precedence is the same.

These rules help avoid ambiguity in expressions such as a + b * c or a = b = c.

Precedence and Associativity Table (Simplified)

Operator Description Associativity
() Parentheses Left to Right
*, /, % Multiplication, Division, Modulus Left to Right
+, - Addition, Subtraction Left to Right
= Assignment Right to Left
?: Ternary Conditional Right to Left

Example Program

#include <stdio.h>

int main() {
    int a = 10, b = 5, c = 2;
    int result;

    result = a - b * c;  // Multiplication happens first

    printf("Result: %d", result);

    return 0;
}

Explanation:

  • b * c → 5 * 2 = 10 (multiplication has higher precedence)
  • a - 10 → 10 - 10 = 0
  • Final output = 0
