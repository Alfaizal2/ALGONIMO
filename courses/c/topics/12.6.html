12.6 Bit Fields

What Are Bit Fields?

Bit fields allow storing data in a structure using a specific number of bits rather than occupying full integer space.

This technique is widely used in:

  • Embedded systems
  • Flags and status registers
  • Packed data formats

Syntax of Bit Fields

struct {
    unsigned int a : 3;
    unsigned int b : 5;
} data;

In this structure: 3 bits are allocated for a and 5 bits for b, totaling only 8 bits.

Example Program

#include <stdio.h>

struct Status {
    unsigned int online : 1;
    unsigned int error  : 1;
    unsigned int busy   : 1;
};

int main() {
    struct Status printer = {1, 0, 1};

    printf("Online: %u\\n", printer.online);
    printf("Error : %u\\n", printer.error);
    printf("Busy  : %u\\n", printer.busy);

    return 0;
}
Output:
Online: 1
Error: 0
Busy: 1

Advantages of Bit Fields

  • Highly efficient memory usage
  • Great for hardware-level programming
  • Allows compact representation of multiple boolean flags

Limitations

  • Cannot take addresses of bit-field members
  • Behavior may vary between systems (padding/alignment differences)
  • No arrays of bit fields allowed
