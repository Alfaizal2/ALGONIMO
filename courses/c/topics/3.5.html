3.5 Comments in C

What Are Comments?

Comments are text notes written inside the source code to explain logic, steps, or purpose of code. The compiler ignores comments, meaning they do not affect your program’s output. Comments help programmers understand code more easily — especially when working in teams or revisiting old code.

  • Improves readability
  • Makes debugging easier
  • Helps document complex code
  • Ignored by compiler, safe for notes

Types of Comments in C

  • Single-line Comment: Begins with // Used for brief notes.
  • Multi-line Comment: Enclosed between /* ... */ Used for longer explanations.

Examples

#include <stdio.h>

int main() {

    // ✅ This is a single-line comment
    printf("Hello, ALGONIMO!\n");

    /* ✅ This is a multi-line comment
       You can write long explanations here
       across multiple lines */
    printf("Learning comments is easy!");

    return 0;
}

Best Practices

  • Use comments to explain why the code exists, not what it does.
  • Keep comments clear and simple.
  • Don’t overuse comments — clean code should be self-explanatory.
  • Avoid writing outdated comments that no longer match the code.
