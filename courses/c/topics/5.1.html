5.1 if, if-else, else-if Statements in C

Introduction

Conditional statements allow your program to make decisions based on given conditions. In C, the most commonly used conditional structures are:

  • if – executes a block only when the condition is true
  • if-else – chooses between two blocks
  • else-if ladder – checks multiple conditions in sequence

if Statement

The if statement executes a block of code only when the specified condition is true.

Syntax

if (condition) {
    // statements
}

Example

#include <stdio.h>

int main() {
    int age = 20;

    if (age >= 18) {
        printf("You are eligible to vote.\n");
    }

    return 0;
}

Output

You are eligible to vote.

Explanation

Since age is 20, the condition age >= 18 becomes true, so the message is printed.

if-else Statement

The if-else statement allows the program to execute one block when a condition is true, and another block when it is false.

Syntax

if (condition) {
    // if block
} else {
    // else block
}

Example

#include <stdio.h>

int main() {
    int number = 5;

    if (number % 2 == 0) {
        printf("The number is even.\n");
    } else {
        printf("The number is odd.\n");
    }

    return 0;
}

Output

The number is odd.

Explanation

Because 5 % 2 == 0 is false, the else block runs.

else-if Ladder

The else-if ladder is used when multiple conditions need to be evaluated. Only the first true condition gets executed.

Syntax

if (condition1) {
    // block 1
} else if (condition2) {
    // block 2
} else {
    // default block
}

Example

#include <stdio.h>

int main() {
    int score = 85;

    if (score >= 90) {
        printf("Grade: A\n");
    } else if (score >= 75) {
        printf("Grade: B\n");
    } else if (score >= 60) {
        printf("Grade: C\n");
    } else {
        printf("Grade: D\n");
    }

    return 0;
}

Output

Grade: B

Explanation

The program checks conditions from top to bottom and stops at the first true one: score >= 75.
