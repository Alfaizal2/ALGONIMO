6.4 Recursion in C

What is Recursion?

Recursion is a technique where a function calls itself to solve smaller parts of a bigger problem. Each recursive function must have:

  • A recursive case → where the function continues calling itself.
  • A base condition → that stops further recursive calls.

Without a base condition, recursion will lead to infinite calls and eventually crash the program (stack overflow).

Syntax

return_type function_name(parameters) {
    if (base_condition) {
        return value;
    }
    return function_name(smaller_problem);   // recursive call
}

Example: Factorial Using Recursion

#include <stdio.h>

int factorial(int n) {
    if (n == 0)
        return 1;            // base condition
    else
        return n * factorial(n - 1);   // recursive call
}

int main() {
    int num = 5;
    printf("Factorial of %d is %d", num, factorial(num));
    return 0;
}

Output

Factorial of 5 is 120

Output Explanation

factorial(5) is calculated like this:

5 × factorial(4)
4 × factorial(3)
3 × factorial(2)
2 × factorial(1)
1 × factorial(0)

When n == 0, it returns 1 and recursion unwinds to compute the final answer:
5 × 4 × 3 × 2 × 1 = 120
