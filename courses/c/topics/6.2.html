6.2 Return Values

Introduction

In C, a function can return a value to the function that called it. This is useful when the function performs a calculation or needs to provide data back to the program.

Every function in C has a return type, which defines the type of value it gives back.

Syntax

return_type function_name(parameters) {
    // statements
    return value;
}

Example

#include <stdio.h>

int add(int a, int b);   // Function declaration

int main() {
    int result = add(5, 3);  // Function call
    printf("Result: %d\n", result);
    return 0;
}

// Function definition
int add(int a, int b) {
    return a + b;  // Returning sum
}

Output

Result: 8

Explanation

  • int add(int a, int b) → Function returns an int value.
  • return a + b → Sends the value back to main().
  • int result = add(5, 3) → Stores returned value.
  • Return values allow functions to provide results to the caller.

Common Return Types

Return Type Description
int Returns integer values
float Returns decimal values
char Returns a single character
void Returns nothing
