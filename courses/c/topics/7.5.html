7.5 Character Arrays vs String Library

Introduction

In C, strings are represented using character arrays. There are two ways to handle them:

  • Character Arrays – Manual handling of characters and null terminator.
  • String Library – Uses built-in functions from <string.h>.

Example 1: Manual Character Array

#include <stdio.h>

int main() {
    char name[] = {'A', 'l', 'g', 'o', 'n', 'i', 'm', 'o', '\0'};
    printf("Name: %s", name);
    return 0;
}
Name: Algonimo

Explanation: You manually create the character array and ensure it ends with '\0'.

Example 2: Using String Library

#include <stdio.h>
#include <string.h>

int main() {
    char name[50];
    strcpy(name, "Algonimo");
    printf("Name: %s", name);
    return 0;
}
Name: Algonimo

Explanation: strcpy() handles copying and null-termination automatically.

Comparison Table

Feature Character Arrays String Library
Memory Handling Manual control of each character Automatic handling via functions
Ease of Use Complex for long strings Very easy using built-in helpers
Function Support None (manual operations) Many: strlen(), strcpy(), strcmp(), strcat()
Flexibility High (low-level control) Limited but convenient

Summary

  • Character arrays form the backbone of strings in C.
  • The string library simplifies most string operations.
  • Use character arrays for low-level control; use <string.h> for practical programming.
