10.1 File Operations: fopen(), fclose()

Introduction

File handling in C allows programs to store data permanently on disk using the FILE management functions defined in <stdio.h>.

  • fopen() – Opens a file in a specific mode.
  • fclose() – Closes the file once you are done using it.

FILE* is a pointer that refers to the file being used.

Example: Using fopen() and fclose()

#include <stdio.h>

int main() {
    FILE *fp;

    fp = fopen("example.txt", "w"); // open file for writing

    if (fp == NULL) {
        printf("File could not be opened!\n");
        return 1;
    }

    fprintf(fp, "Hello, Algonimo!\n");
    fclose(fp);

    printf("File created and data written successfully.");
    return 0;
}
Output:
Creates example.txt with content: Hello, Algonimo!

fopen() Modes

Mode Description
"r" Open for reading (file must exist)
"w" Open for writing (creates or overwrites file)
"a" Append to file (creates if not exists)
"r+" Read + Write (file must exist)
"w+" Read + Write (overwrite)

Summary

  • fopen() opens a file using a specific mode.
  • FILE * stores the reference to the opened file.
  • fclose() must always be called to free system resources.
