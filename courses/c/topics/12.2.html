12.2 Linked List Basics

Introduction

A linked list is a linear data structure where each element (called a node) stores data and a pointer to the next node. Linked lists allow **dynamic memory allocation**, unlike arrays.

Node Structure

struct Node {
    int data;
    struct Node* next;
};

Each node contains:

  • data — value stored in the node
  • next — pointer to the next node

Example: Creating & Displaying a Linked List

#include <stdio.h>
#include <stdlib.h>

struct Node {
    int data;
    struct Node* next;
};

int main() {
    struct Node* head = NULL;
    struct Node* second = NULL;
    struct Node* third = NULL;

    head = (struct Node*)malloc(sizeof(struct Node));
    second = (struct Node*)malloc(sizeof(struct Node));
    third = (struct Node*)malloc(sizeof(struct Node));

    head->data = 10;
    head->next = second;

    second->data = 20;
    second->next = third;

    third->data = 30;
    third->next = NULL;

    struct Node* temp = head;
    while (temp != NULL) {
        printf("%d ", temp->data);
        temp = temp->next;
    }

    return 0;
}
Output:
10 20 30

Benefits of Linked List

  • Dynamic size — grows and shrinks as needed
  • Easy insertion/deletion
  • No memory wastage unlike arrays
  • Efficient for implementing complex structures (queues, stacks, graphs)
