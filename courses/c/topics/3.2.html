3.2 Variables and Constants

What Are Variables?

Variables are containers for storing data values. They allow your program to store and manipulate data dynamically. In C, you must declare a variable with a specific type before using it. 

int age = 25;
float price = 99.99;

Rules for Naming Variables

  • Start with a letter or underscore (_)
  • Can include letters, digits, and underscores
  • Case-sensitive (e.g., Age and age are different)
  • Cannot use C reserved keywords

What Are Constants?

Constants are fixed values that cannot be changed during the execution of a program. They help keep your code safe from accidental changes. 

const float PI = 3.14;
#define MAX 100

Example Program

#include <stdio.h>
#define PI 3.14

int main() {
    int radius = 5;
    float area;

    area = PI * radius * radius;

    printf("Area = %.2f", area);
    return 0;
}
