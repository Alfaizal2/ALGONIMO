2.1 Installing a C Compiler

Introduction

Before you start writing and running C programs, you need a C compiler — a software tool that converts your C code into an executable program. In this module, you’ll install a compiler depending on your operating system. Don't worry — it's simple and beginner-friendly.

Windows

Windows does not include a built-in C compiler, so you must install one. The most recommended setup for beginners is: VS Code + GCC (MinGW-w64).

✅ Method 1: VS Code + MinGW-w64 (Recommended)

  • Download VS Code from: code.visualstudio.com
  • Install MinGW-w64 from: mingw-w64.org
  • During installation, choose:
    Version: latest
    Architecture: x86_64
    Threads: posix
    Exception: seh
  • Add MinGW bin folder to PATH.
  • Install the “C/C++” Microsoft extension in VS Code.

✅ Method 2: Code::Blocks (Easy for Beginners)

Code::Blocks comes with a built-in compiler if you choose the right setup file.

  • Download from: codeblocks.org
  • Select the installer that includes MinGW.
  • Open Code::Blocks → New Project → Console Application → C.

macOS

macOS users can install a C compiler very easily using the Xcode Command Line Tools, which includes GCC/Clang.

  • Open the App Store → Install Xcode (optional).
  • Then open Terminal and run:
    xcode-select --install
  • After installation, type gcc --version to verify.

Linux

Most Linux distributions come with GCC preinstalled. If not, install it using your package manager.

  • Ubuntu / Debian: sudo apt install build-essential
  • Fedora: sudo dnf install gcc gcc-c++ make
  • Arch Linux: sudo pacman -S base-devel

After installation, run gcc --version to confirm.

Online Compilers

If you don’t want to install anything, you can practice C online. These tools are great for quick experiments:

  • Programiz Online Compiler – clean and beginner friendly.
  • OnlineGDB – powerful debugger and compiler.
  • Replit – collaborative coding environment.
