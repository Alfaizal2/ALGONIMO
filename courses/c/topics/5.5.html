5.5 break, continue, goto in C

Introduction

C provides three special jump statements that change the normal flow of loops or program execution:

Overview of Jump Statements

Statement Description
break; Stops the loop or switch immediately.
continue; Skips current loop iteration and moves to the next.
goto label; Jumps to a specific labeled location in the program.

break Statement – Example

#include <stdio.h>

int main() {
    for(int i = 1; i <= 5; i++) {
        if(i == 3) break;
        printf("%d\n", i);
    }
    return 0;
}
Output:
1
2

Explanation: The loop stops entirely when i == 3.

continue Statement – Example

#include <stdio.h>

int main() {
    for(int i = 1; i <= 5; i++) {
        if(i == 3) continue;
        printf("%d\n", i);
    }
    return 0;
}
Output:
1
2
4
5

Explanation: When i == 3, that iteration is skipped.

goto Statement – Example

#include <stdio.h>

int main() {
    printf("Before jump\n");
    goto end;

    printf("This line is skipped\n");

end:
    printf("After jump\n");
    return 0;
}
Output:
Before jump
After jump

Explanation: Control jumps directly to the end: label.

Caution

  • goto should be avoided in modern programming.
  • Use break and continue carefully to keep code readable.
