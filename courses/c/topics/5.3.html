5.3 Loops in C

Introduction

Loops are used to execute a block of code multiple times. C provides three primary loop constructs to handle repeated tasks efficiently:

Types of Loops in C

Loop Type Description
while Checks condition first, then executes the loop body.
do-while Executes loop body once, then checks condition.
for Ideal for loops with initialization, condition, and increment.

while Loop

The while loop checks the condition before executing the loop body.

int i = 1;
while (i <= 5) {
    printf("%d\n", i);
    i++;
}
Output:
1
2
3
4
5

do-while Loop

The do-while loop executes the loop body first, then checks the condition.

int i = 1;
do {
    printf("%d\n", i);
    i++;
} while (i <= 5);
Output:
1
2
3
4
5

for Loop

The for loop is best suited for situations with a known number of iterations.

for (int i = 1; i <= 5; i++) {
    printf("%d\n", i);
}
Output:
1
2
3
4
5

Summary

  • while → checks condition first
  • do-while → runs at least once
  • for → perfect for counter-controlled loops
