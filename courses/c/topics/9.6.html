9.6 Structures vs Unions

Overview

Structures and unions are user-defined data types in C. Both allow grouping variables of different data types, but they differ in memory allocation and usage behavior.

✅ Use structures when you need to store all values simultaneously.
✅ Use unions when memory is limited or only one value is used at a time.

Key Differences

Feature Structure Union
Memory Allocation Each member gets separate memory. All members share one memory block.
Total Size Sum of all members. Equal to largest member.
Value Storage All members can store values simultaneously. Only one valid member at a time.
Use Case Store complete records (student, employee). Memory-efficient representation (sensor data, hardware values).

Example Comparison

// Structure example
struct Student {
    int roll;
    float marks;
};

// Union example
union Item {
    int code;
    float price;
};

✅ In a structure, both roll and marks have their own memory.
✅ In a union, code and price share the same memory.
