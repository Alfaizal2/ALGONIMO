7.3 Introduction to Strings in C

What is a String?

A string in C is a sequence of characters stored in a character array and terminated with a special character: '\0' (null character).

Since C does not have a built-in string type, strings are handled using character arrays and library functions from <string.h>.

Declaring Strings

char str1[20];            // Empty character array
char str2[20] = "Hello";  // Initialized string
char str3[]  = "World";   // Size decided automatically

Example: Reading a String

#include <stdio.h>

int main() {
    char name[30];

    printf("Enter your name: ");
    scanf("%s", name); // reads until space

    printf("Hello, %s!", name);
    return 0;
}

Output

Enter your name: Alice
Hello, Alice!

Reading Multi-word Strings

scanf("%s") stops input when it finds a space. To read full sentences, use fgets(): 

fgets(name, sizeof(name), stdin);

Example: Reading Full Name with fgets()

#include <stdio.h>

int main() {
    char fullName[50];

    printf("Enter full name: ");
    fgets(fullName, sizeof(fullName), stdin);

    printf("You entered: %s", fullName);

    return 0;
}
