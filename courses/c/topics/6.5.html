6.5 Storage Classes in C

Introduction

Storage classes in C determine the scope (where a variable can be accessed), lifetime (how long it exists in memory), and default initial value.

The four main storage classes are:

  • auto – default local variable
  • static – retains value between function calls
  • extern – refers to a global variable from another file
  • register – suggests fast access using CPU registers

Storage Class Overview

Storage Class Scope Lifetime Default Value Keyword
auto Local to block Until function ends Garbage value auto
static Local or Global Entire program Zero (0) static
extern Global (across files) Entire program Zero (0) extern
register Local Until function ends Garbage value register

Example Program

#include <stdio.h>

// static variable example
void demoStatic() {
    static int count = 0; // retains value between calls
    count++;
    printf("Static count: %d\n", count);
}

int main() {

    auto int a = 10;        // auto is default local variable
    register int r = 5;     // suggested for fast access

    printf("Auto variable: %d\n", a);
    printf("Register variable: %d\n", r);

    demoStatic();
    demoStatic();
    demoStatic();

    return 0;
}

Output

Auto variable: 10
Register variable: 5
Static count: 1
Static count: 2
Static count: 3

Output Explanation

  • auto: A normal local variable, destroyed after the function ends.
  • register: Suggested to be stored in CPU registers for faster access.
  • static: Retains its value across multiple function calls.

When Should You Use Them?

  • auto: Default choice for local variables.
  • static: When the value must persist between calls.
  • extern: When accessing global variables from other files.
  • register: For frequently used variables like loop counters.
