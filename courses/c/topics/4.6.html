4.6 Bitwise Operators in C

Bitwise operators allow you to work directly with **individual bits** (0s and 1s). They are faster than arithmetic operations and are widely used in:

  • Low-level embedded programming
  • Cryptography and security algorithms
  • Network packet processing
  • High-performance mathematical operations

Bitwise Operators Overview

Operator Name Example Description
& Bitwise AND a & b 1 only if both bits are 1
| Bitwise OR a | b 1 if at least one bit is 1
^ Bitwise XOR a ^ b 1 if bits are different
~ Bitwise NOT ~a Inverts every bit
<< Left Shift a << 1 Shifts bits left (×2 each shift)
>> Right Shift a >> 1 Shifts bits right (÷2 each shift)

Example Program

#include <stdio.h>

int main() {
    int a = 5, b = 3;

    printf("a & b = %d\n", a & b);
    printf("a | b = %d\n", a | b);
    printf("a ^ b = %d\n", a ^ b);
    printf("~a = %d\n", ~a);
    printf("a << 1 = %d\n", a << 1);
    printf("a >> 1 = %d\n", a >> 1);

    return 0;
}
Output:
a & b = 1
a | b = 7
a ^ b = 6
~a = -6
a << 1 = 10
a >> 1 = 2

Explanation:

  • 5 = 0101 and 3 = 0011 (4-bit binary)
  • & checks matching 1-bits → 0001 = 1
  • | merges bits → 0111 = 7
  • ^ highlights differences → 0110 = 6
  • ~5 flips bits → -6 (two’s complement)
  • << shifting left doubles → 10
  • >> shifting right halves → 2

Real-Life Example: Checking a Bit

#include <stdio.h>

int main() {
    int status = 10;  // 1010 in binary

    if (status & 2) {
        printf("2nd bit is ON");
    } else {
        printf("2nd bit is OFF");
    }

    return 0;
}
Output: 2nd bit is ON
