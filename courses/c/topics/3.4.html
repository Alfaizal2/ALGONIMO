3.4 Input and Output in C

Introduction

In C programming, input and output operations allow your program to interact with the user. These operations are performed using standard library functions printf() and scanf(), both included in the <stdio.h> header file.

printf() Function

The printf() function is used to display text or values on the screen. It supports format specifiers to display variables properly. 

printf("Welcome to ALGONIMO!");

Example with variables:

int age = 20;
printf("Age: %d", age);

scanf() Function

The scanf() function reads input from the user. It stores the value inside a variable using its memory address (& operator). 

int age;
scanf("%d", &age);

Important: Never forget the & symbol when reading numbers.

Common Format Specifiers

Specifier Meaning Example
%d Integer scanf("%d", &num);
%f Floating-point number scanf("%f", &price);
%c Single character scanf("%c", &grade);
%s String (word) scanf("%s", name);

Example Program

#include <stdio.h>

int main() {
    int age;
    char name[20];

    printf("Enter your name: ");
    scanf("%s", name);

    printf("Enter your age: ");
    scanf("%d", &age);

    printf("Hello %s, you are %d years old.", name, age);
    return 0;
}
