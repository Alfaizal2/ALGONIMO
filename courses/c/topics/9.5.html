9.5 Introduction to Unions

What is a Union?

A union is a special user-defined data type in C that allows multiple members to share the same memory location.

🔹 Only one member can hold a valid value at a time. 🔹 Useful for efficient memory usage.

Union Syntax

union UnionName {
    data_type member1;
    data_type member2;
    ...
};

Important Note

Since all members share the same memory space, writing to one member overwrites the others.

Memory Usage

  • Structure: Allocates memory for every member.
  • Union: Allocates memory equal to the size of the largest member.

Quick Summary

Concept Union
Multiple Members Only one valid at a time
Memory Size Size of the largest member
Use Case Efficient memory storage
