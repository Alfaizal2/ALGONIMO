2.2 Writing Your First C Program

Introduction

Now that you have installed a C compiler, it’s time to write your very first C program. We’ll start with the classic "Hello, World!" program — the simplest and most common way to verify that your compiler, editor, and environment are all set up correctly.

This small program introduces the basic structure of a C program and how output works.

Code Example

#include <stdio.h>

int main() {
    printf("Hello, World!\n");
    return 0;
}

Try it Yourself (Run the Code!)

Output: Output will appear here...

Explanation

  • #include <stdio.h> — This imports the Standard Input/Output library, which provides the printf() function.
  • int main() — This is the starting point of every C program.
  • printf("Hello, World!\n"); — This prints text to the screen. The \n adds a new line.
  • return 0; — This ends the program and tells the system everything ran successfully.

Output

When you run the program, you will see:

Hello, World!

If you see the above output, congratulations — your C environment is working perfectly!
