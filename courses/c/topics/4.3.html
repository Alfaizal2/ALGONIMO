    4.3 Logical Operators in C

    Logical operators are used to combine multiple conditions and make decisions. They return:

    • 1 (true) – Condition is satisfied
    • 0 (false) – Condition is not satisfied
    • Commonly used inside if, while, and multi-condition checks

    Overview of Logical Operators

    Operator Symbol Description Example Output
    Logical AND && True only if both conditions are true (5 > 2) && (3 < 6) 1
    Logical OR || True if at least one condition is true (5 < 2) || (3 < 6) 1
    Logical NOT ! Reverses the logic !(4 == 4) 0

    Example 1: Logical AND (&&)

    #include <stdio.h>

int main() {
    int a = 5, b = 10;
    printf("%d", (a < b) && (b > 0));
    return 0;
}
    Output: 1

    Explanation: Both conditions are true → AND returns 1.

    Example 2: Logical OR (||)

    #include <stdio.h>

int main() {
    int x = 3, y = 7;
    printf("%d", (x > y) || (y > 5));
    return 0;
}
    Output: 1

    Explanation: One condition is true → OR returns 1.

    Example 3: Logical NOT (!)

    #include <stdio.h>

int main() {
    int x = 4;
    printf("%d", !(x == 4));
    return 0;
}
    Output: 0

    Explanation: True becomes False → 0.

    Real-Life Example

    #include <stdio.h>

int main() {
    int age = 20;
    int hasID = 1;

    if (age >= 18 && hasID) {
        printf("Access Granted");
    } else {
        printf("Access Denied");
    }
    return 0;
}
    Output: Access Granted
