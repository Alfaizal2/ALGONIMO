8.2 Pointer Arithmetic

What is Pointer Arithmetic?

Pointer arithmetic allows you to perform arithmetic operations on pointers such as ++, --, +, and -. It is commonly used when working with arrays and dynamic memory.

The key rule: Pointer arithmetic moves in steps equal to the size of the data type.

Incrementing a Pointer

When you increment a pointer, it moves to the next element—not the next byte. For an int*, it moves by 4 bytes on most systems. 

#include <stdio.h>

int main() {
    int arr[] = {10, 20, 30};
    int *ptr = arr;

    printf("First value: %d\n", *ptr);
    ptr++;  
    printf("Second value: %d\n", *ptr);

    return 0;
}
Output:
First value: 10
Second value: 20

Subtracting Pointers

Pointer subtraction tells you how many elements apart two pointers are—only valid when both pointers point inside the same array. 

#include <stdio.h>

int main() {
    int arr[] = {10, 20, 30, 40};
    int *ptr1 = &arr[1]; // 20
    int *ptr2 = &arr[3]; // 40

    int diff = ptr2 - ptr1;

    printf("Pointer difference = %d\n", diff);
    return 0;
}
Output:
Pointer difference = 2

Summary Table

Operation Meaning
ptr++ Moves to the next element
ptr-- Moves to the previous element
ptr + n Moves ahead by n elements
ptr1 - ptr2 Returns element distance between pointers
