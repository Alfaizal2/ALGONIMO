10.5 Binary File Operations

What is a Binary File?

Binary files store data in raw binary form (0s and 1s). They are faster, more compact, and ideal for storing:

  • Images
  • Audio files
  • Executable code
  • Structures and complex data

Unlike text files, binary files preserve the exact memory representation of data.

Functions Used in Binary File Handling

  • fopen() – open binary file ("rb", "wb", "ab")
  • fread() – read binary data
  • fwrite() – write binary data
  • fclose() – close file

Example: Writing & Reading a Binary File

#include <stdio.h>

struct Student {
    char name[50];
    int age;
};

int main() {
    struct Student s1 = {"John", 20};

    // Write to binary file
    FILE *fptr = fopen("student.dat", "wb");
    fwrite(&s1, sizeof(s1), 1, fptr);
    fclose(fptr);

    // Read from binary file
    struct Student s2;
    fptr = fopen("student.dat", "rb");
    fread(&s2, sizeof(s2), 1, fptr);
    fclose(fptr);

    printf("Name: %s\nAge: %d\n", s2.name, s2.age);
    return 0;
}
Output:
Name: John
Age: 20

Note: Always check if the file opened successfully before using fread() or fwrite().

Binary File Modes

Mode Description
"rb" Open binary file for reading.
"wb" Open for writing (overwrites existing file).
"ab" Open for appending in binary mode.
"rb+" Open for reading and writing.
"wb+" Read + write (overwrites existing file).

Summary

  • Binary files store raw data, making them more efficient.
  • Use fread() and fwrite() for binary operations.
  • Useful for structures, multimedia files, and performance-critical programs.
