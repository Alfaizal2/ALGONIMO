7.4 String Functions in C

Introduction

The C standard library <string.h> provides a variety of functions to process and manipulate strings. Here are three of the most commonly used string functions.

strlen()

The strlen() function returns the length of a string (excluding the null character '\0'). 

#include <stdio.h>
#include <string.h>

int main() {
    char str[] = "Algonimo";
    printf("Length = %lu", strlen(str));
    return 0;
}
Length = 8

strcpy()

The strcpy() function copies a string from source to destination. 

#include <stdio.h>
#include <string.h>

int main() {
    char src[] = "C Programming";
    char dest[50];

    strcpy(dest, src);

    printf("Copied String = %s", dest);
    return 0;
}
Copied String = C Programming

strcmp()

The strcmp() function compares two strings. Return values:

  • 0 → Strings are equal
  • < 0 → First string is smaller
  • > 0 → First string is greater
#include <stdio.h>
#include <string.h>

int main() {
    char a[] = "Apple";
    char b[] = "Banana";

    int result = strcmp(a, b);

    if (result == 0)
        printf("Strings are equal");
    else if (result < 0)
        printf("a is less than b");
    else
        printf("a is greater than b");

    return 0;
}
a is less than b
