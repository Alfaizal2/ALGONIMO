4.5 Increment & Decrement Operators in C

Increment and decrement operators are **unary operators** used to increase or decrease a value by 1. They are extremely common in loops, counters, and iterative logic.

  • Increment (++): increases value by 1
  • Decrement (--): decreases value by 1
  • Both have Prefix and Postfix forms
  • Prefix updates first → value used after update
  • Postfix uses value first → update happens after

Overview of Increment & Decrement Operators

Operator Name Example Description
++a Pre-increment x = ++a; Increments a first → then assigns to x
a++ Post-increment x = a++; Assigns old value to x → then increments a
--a Pre-decrement x = --a; Decrements first → new value stored in x
a-- Post-decrement x = a--; Old value goes to x → then a decreases

Example Program

#include <stdio.h>

int main() {
    int a = 5, x;

    x = ++a;  // Pre-increment
    printf("x = %d, a = %d\n", x, a);

    x = a--;  // Post-decrement
    printf("x = %d, a = %d", x, a);

    return 0;
}
Output: x = 6, a = 6
x = 6, a = 5

Explanation:

  • ++a → increases first → a becomes 6 → x receives 6
  • a-- → x receives old value 6 → then a becomes 5
  • Final values: x = 6, a = 5

Real-Life Example

#include <stdio.h>

int main() {
    int visitors = 0;

    visitors++;   // new visitor enters
    visitors++;   // another enters
    visitors--;   // one leaves

    printf("Current Visitors: %d", visitors);
    return 0;
}
Output: 1
